# Atividades de Pesquisa Operacional

Este repositório contém as resoluções das atividades propostas na lista de exercícios de Pesquisa Operacional.

## Questões resolvidas

Foram resolvidas as seguintes questões:

- **Questão 1**: implementação de uma meta-heurística de solução única para o problema do **Bin Packing**.
  - Diretório: `Atividades_Pesquisa_operacional/questao1/`
  - A explicação da solução está documentada em um arquivo Markdown dentro da própria pasta.

- **Questão 2**: implementação dos modelos de **Programação Linear Inteira** vistos em aula.
  - Diretório: `Atividades_Pesquisa_operacional/questao2/`
  - A explicação da solução também está documentada em um arquivo Markdown dentro da própria pasta.

## Organização do repositório

```bash
Atividades_Pesquisa_operacional/
├── questao1/
│   └── README.md
└── questao2/
    └── README.md
```

Cada questão possui sua própria pasta e um arquivo `.md` explicando, de forma resumida, o que foi desenvolvido.

## Referência

As atividades foram desenvolvidas com base na lista de exercícios da disciplina de Pesquisa Operacional, que solicita:

1. Uma meta-heurística baseada em busca local para o problema do Bin Packing.
2. A implementação dos modelos de Programação Linear Inteira vistos em aula.
